# Unreal plugin icon sources

- `dcc-mcp-unreal-plugin-icon-source.png`: generated with the built-in OpenAI
  ImageGen tool on 2026-07-31. The prompt requested a DCC-MCP navy, blue, cyan,
  and teal protocol-network base with no text, plug, or third-party trademark.
- `unreal/plugin/Resources/Icon128.png`: the generated base with a deterministic
  DCC-MCP `MCP` hexagon overlay, exported as the 128×128 PNG required by the
  Unreal Engine Plugin Browser.
- The installed Unreal Engine white circle-U asset was inspected as an
  authoritative composition reference, but is not embedded in the final icon.
  Epic-owned marks require the applicable trademark permission and must not be
  redrawn or combined into a third-party icon by default.
